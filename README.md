# Programmering B · 2026

Dette repository indeholder undervisningsmaterialer, links, kodeeksempler og
opgaver til Programmering B. Indholdet bliver udbygget løbende gennem
skoleåret.

## Undervisningsside

Materialet bliver samlet på kursets hjemmeside:

[Åbn undervisningssiden](https://louissse.github.io/programmering-b-2026/)

## Indhold

```text
programmering-b-2026/
├── .agents/         # Lokal skill til undervisningsplanlægning
├── docs/            # Arbejdsgrundlag, faglige kilder og beslutninger
├── index.html       # Forsiden til undervisningssiden
├── main.css         # Sidens udseende
└── studietur/       # Særlig opgaveside til dataindsamling på studietur
```

Nye forløb får deres egen nummererede mappe, så materialerne bliver vist i den
rækkefølge, vi arbejder med dem.

## Dokumentation

Agenters og underviseres arbejdsgrundlag findes i
[`docs/README.md`](docs/README.md). Her ligger også de versionsbestemte
officielle kilder til planlægning af Programmering B.

## Hent materialet

Du kan hente en kopi af hele repository'et med GitHub Desktop eller med Git i
terminalen:

```bash
git clone https://github.com/louissse/programmering-b-2026.git
```

Hvis du allerede har hentet repository'et, kan du hente de seneste ændringer
med:

```bash
git pull
```
