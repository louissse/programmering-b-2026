01 Lokalt udviklingsmiljø VS Code, Live Server og din kode fra p5.js Web Editor Åbn

I uge 41 satte vi vores lokale udviklingsmiljø op. Her kan du følge trinene igen, hvis du var fraværende eller har brug for at få opsætningen på plads.

Installér værktøjerne

  1. Hent og installér Visual Studio Code til din computer.
  2. Åbn Extensions i VS Code. Søg efter Live Server af Ritwick Dey, og installér udvidelsen.
  3. Åbn indstillingerne i VS Code, vælg brugerindstillingerne, og søg efter chat.disableAIFeatures. Slå Chat: Disable AI Features til. Det slår de indbyggede AI-funktioner og Copilot fra. Har du installeret andre udvidelser med AI-hjælp, skal du også deaktivere dem. Se VS Codes vejledning om at slå AI fra.

Åbn din p5.js-skitse lokalt

  1. Åbn en af dine fungerende skitser i p5.js Web Editor, og download projektet via menuen File. Pak ZIP-filen ud.
  2. Vælg File → Open Folder i VS Code, og åbn den udpakkede projektmappe. Åbn hele mappen, så både HTML-filen, din JavaScript-kode og eventuelle billeder og andre filer er med.
  3. Find index.html i filoversigten. Højreklik på filen, og vælg Open with Live Server. Skitsen åbner nu i browseren via en lokal server.
  4. Kontrollér, at skitsen ser ud og reagerer som i webeditoren. Afprøv også den interaktion, du har lavet med mus eller tastatur.
  5. Lav en lille synlig ændring i sketch.js, og gem filen. Kontrollér i browseren, at ændringen vises.

Hvis skitsen ikke virker

  • Kontrollér, at du har pakket ZIP-filen ud og åbnet den rigtige mappe.
  • Start siden med Live Server via index.html.
  • Kontrollér filnavne og stier til billeder, lyd og andre filer.
  • Se efter fejl i browserens konsol, og brug fejlbeskeden til at finde den relevante fil og linje.

Uge 44 · 90 minutter

Fra arrays til data. Vi undersøger et søjlediagram og ændrer det med arrays, loops og betingelser.

02 Byg videre på et søjlediagram Data, søjler, tekst og farver Åbn

Mål: Du kan forklare, hvordan et loop tegner værdierne i et array, og ændre diagrammet.

1. Fælles start · 10 min.

Vi ser et diagram med opdigtede temperaturer. Hvad sker der, hvis vi ændrer et tal eller tilføjer en værdi?

2. Hent og undersøg koden · 15 min.

Find startprojektet på GitHub

  1. Åbn repositoryet. Vælg Code → Download ZIP, og pak filen ud.
  2. Åbn mappen 02_data/eksempler/01_soejlediagram i VS Code. Start index.html med Live Server.
  3. Åbn sketch.js. Find arrayet og loopet. Følg sammen, hvordan én værdi bliver til én søjle.

3. Ændr diagrammet · 30 min.

  1. Ændr to temperaturer. Gæt resultatet, før du kører koden.
  2. Fjern en værdi, og tilføj den igen. Hvad styrer antallet af søjler?
  3. Vis temperaturen over hver søjle med text(). Brug samme arrayværdi og x-position som søjlen.

Hjælp: text() og rect().

4. Tilføj farver · 20 min.

Brug if/else til at give temperaturer på mindst 18 °C en anden farve. Lav én ændring ad gangen, gem og test.

Videre herfra

Tilføj flere målinger. Beregn afstanden mellem søjlerne ud fra arrayets længde, så de stadig passer på lærredet.

Ekstra: Vis gennemsnittet

  1. Brug et loop til at lægge temperaturerne sammen. Start summen på 0, hver gang du beregner den.
  2. Beregn gennemsnittet ved at dividere summen med antallet af målinger.
  3. Tegn en vandret linje ved gennemsnittet med line(). Brug samme bundlinje og skala som søjlerne, og vis gennemsnittet som tekst.

Test med et array, hvor alle temperaturer er 15. Rammer linjen toppen af alle søjlerne? Ændr derefter ét tal, og undersøg, hvordan gennemsnittet flytter sig.

5. Vis og forklar · 15 min.

Vis diagrammet til en makker. Forklar forskellen på i og temperaturer[i].

Skriv korte kommentarer ved loopet og din betingelse. Forklar, hvad de gør, og hvorfor du har valgt grænsen for farveskift. Gem projektet.

Lektie til uge 45 · Indsaml dine egne data

Vælg noget fra din hverdag, fx minutter med musik, transporttid eller antal cykler, du møder på vej til skole.

  • Indsaml 5–7 målinger inden næste modul. Brug samme enhed og samme måde at måle på hver gang.
  • Notér tidspunkt eller kategori, tal og enhed for hver måling. De bliver felter i et objekt, når vi samler dataene i uge 45.
  • Vælg noget, du har lyst til at vise andre. Medbring tallene og en kort forklaring på, hvordan du målte.

Du kan også tælle fx bøger, planter eller kopper i forskellige rum, hvis du vil indsamle det hele på én dag.

Uge 45 · 90 minutter

Visualisér din hverdag. Du skriver dit eget array og loop og vælger, hvordan dine målinger skal vises.

03 Dine data, dit udtryk Egne målinger, objekter og loops Åbn

Mål: Du kan selv skrive et array med objekter og et loop, der viser dine data. Du kan forklare din løsning og genkende dataene som JSON.

1. Samme data, forskellige udtryk · 10 min.

Vi genopfrisker arrays og loops fra uge 44 og undersøger En uge i musik. Skift mellem søjler, bobler og ugehjul. Hvilken visning gør det lettest at sammenligne dagene? Hvordan bruges den samme værdi til at tegne forskellige figurer?

2. Fra måling til objekt og JSON · 15 min.

Et objekt samler oplysninger om én måling. Vi bruger felterne navn, vaerdi og enhed. Et array holder styr på flere målinger.

Vi undersøger samme data som JavaScript og JSON på GitHub. Find én måling, og læs dens felter. Vi prøver at hente dens vaerdi med punktnotation.

JSON er et tekstformat til data. Feltnavne og tekst står i dobbelte anførselstegn. JSON har hverken variabeldeklarationer eller kommentarer. I dag skriver vi objekterne i JavaScript. Senere indlæser vi dem fra en JSON-fil.

3. Skriv dit eget array og loop · 45 min.

Gem arbejdet fra uge 44. Hent den tomme skitse fra GitHub, og åbn den med Live Server som i uge 44.

  1. Skriv selv et array med ét objekt pr. indsamlet måling. Brug felterne navn, vaerdi og enhed. Mangler du data, så lav 5–7 opdigtede målinger og skriv tydeligt, at de er opdigtede.
  2. Vælg et udtryk: søjler, cirkler, blomster, bygninger eller din egen idé. Beslut, hvad størrelse, placering eller farve viser.
  3. Hent vaerdi fra det første objekt med punktnotation, og brug den til at tegne én figur.
  4. Skriv et for-loop, der tegner én figur pr. værdi. Brug arrayets længde som grænse, og giv figurerne hver sin plads.
  5. Vis værdier og enhed, og gør det tydeligt, hvad figurerne repræsenterer. Hent også navn og enhed fra objekterne.

Skriv selv koden. Brug gerne p5.js-reference og dine noter. Går du i stå, så undersøg én relevant del af eksemplet fra uge 44, luk det igen, og prøv selv.

Kommentér, hvad loopet gør, og begrund dit valg af figurer og skala. Skriv også, hvordan du indsamlede dine data.

Videre herfra

Brug en betingelse til at fremhæve bestemte værdier, eller vis de samme data på to måder. Vil du videre, så saml tegningen i en funktion med arrayet som parameter.

4. Test med en makker · 10 min.

Test med en kopi af dine data. Prøv en måling med værdien 0, en stor værdi og et andet navn. Prøv også et kortere og et længere array. Kan din makker aflæse data og enhed? Find ud af, hvad din visualisering kan håndtere, og ret ét problem, hvis du finder et.

5. Gem og saml op · 10 min.

Gem projektet med dine kommentarer. Skriv kort øverst i sketch.js, hvilke test du lavede, hvad de viste, og hvad der endnu ikke virker.

Aflevér dit projekt i afleveringsmodulet i Teams. Visualiseringen og din dokumentation indgår i vurderingen. Der lægges vægt på din brug af arrays, objekter og loops, dine forklaringer af kode og valg samt dine test.

Det skal du kunne forklare

  • Hvordan arrayet, objekterne og loopet bruges.
  • Hvordan du henter et felts værdi, og hvad JSON bruges til.
  • Hvad du selv har ændret, og hvorfor du valgte den løsning.
  • Hvordan du testede, og hvad testen viste.
