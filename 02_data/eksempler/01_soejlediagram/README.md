# Søjlediagram · startkode til uge 44 og 45

1. Hent repositoryet fra GitHub med **Code → Download ZIP**, og pak filen ud.
2. Åbn denne mappe i VS Code.
3. Højreklik på `index.html`, og vælg **Open with Live Server**.

Projektet henter p5.js 2.3.3 fra et CDN og kræver derfor internet ved indlæsning.
Temperaturerne er opdigtede og angivet i °C.

Opgaverne står på [forløbssiden](https://louissse.github.io/programmering-b-2026/02_data#uge44).
Gem en kopi af dit arbejde fra uge 44, før du fortsætter i uge 45.

Dokumentér dine ændringer med korte kommentarer i koden. Forklar formålet og
begrund dine valg. Notér test og resultater øverst i `sketch.js`.
Aflevér dit projekt i afleveringsmodulet i Teams.
