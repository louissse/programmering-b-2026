# Egne data · uge 45

Hent repositoryet fra GitHub med **Code → Download ZIP**, og pak filen ud.
Åbn `02_data/eksempler/02_egne_data` i VS Code.
Start `index.html` med **Open with Live Server**.

Brug dine indsamlede data fra lektien. Skriv selv et array af objekter
med felterne `navn`, `vaerdi` og `enhed`, og et loop i `sketch.js`.
Brug punktnotation til at hente felterne fra hvert objekt.
Vælg selv, om du vil vise data med søjler, cirkler eller andre figurer.
Følg opgaven på [forløbssiden](../../index.html#uge-45).
Ret overskrift og beskrivelse i `index.html`, så de passer til dine data.
Projektet henter p5.js fra et CDN og kræver internet ved indlæsning.

Forklar din kode og dine valg med korte kommentarer.
Aflevér dit projekt i afleveringsmodulet i Teams.

Visualiseringen og dokumentationen fra uge 45 indgår i vurderingen.
Der lægges vægt på arrays, objekter og loops, forklaringer af kode og valg
samt test af løsningen.
