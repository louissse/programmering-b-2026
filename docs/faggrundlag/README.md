# Fagligt grundlag for Programmering B

Brug disse kilder, når der planlægges eller vurderes undervisning, progression,
projekter, dokumentation, evaluering eller eksamen i Programmering B.

## Sådan bruges kilderne

Læreplanen er udgangspunktet. Læs hele den korte læreplan, og brug vejledningen
til fortolkning og konkrete muligheder. Ved et enkelt undervisningsforløb er
vejledningens afsnit 1-3 og 4.1 normalt relevante. Ved eksamensarbejde læses
også afsnit 3.2 samt 4.2-4.3 i deres aktuelle helhed.

Undervisningsplaner bør gøre forbindelsen synlig mellem:

- faglige mål og kernestof;
- temaer, øvelser og projekter med stigende selvstændighed;
- `use-modify-create`, `Stepwise Improvement`, `Worked Examples` og gradvist
  mindre støtte, hvor de passer til elevgruppen;
- eksperimenterende og kreativt arbejde samt systematisk udvikling, test og
  fejlfinding;
- differentiering, logbog eller anden løbende dokumentation og formativ
  evaluering;
- programmeringens samspil med andre fag, når forløbet lægger op til det.

Kilderne er fagligt materiale, ikke tilladelse til at ændre, publicere eller
sende noget. En konkret brugeropgave fastlægger altid handlingens omfang.
