# Dokumentation for agenter

Denne mappe samler den information, som ikke bør fylde i `AGENTS.md`.

## Find den rigtige information

- [`arbejdsgrundlag.md`](arbejdsgrundlag.md): målgruppe, didaktisk retning,
  repositorystruktur, webkonventioner og færdigkriterier.
- [`faggrundlag/README.md`](faggrundlag/README.md): læreplan, vejledning og
  regler for, hvordan de bruges ved undervisningsplanlægning.
- [`beslutninger.md`](beslutninger.md): korte, varige projektbeslutninger og
  begrundelser.
- [`.agents/skills/plan-undervisning/SKILL.md`](../.agents/skills/plan-undervisning/SKILL.md):
  arbejdsgang til at planlægge eller vurdere undervisningsforløb.

`README.md` i repositoryets rod er den offentlige introduktion til mennesker.
Dokumentationen her er arbejdsgrundlag for undervisere og agenter og skal ikke
automatisk vises på elevsiden.

## Vedligeholdelse

Opdatér den fil, der ejer informationen, frem for at gentage samme regel flere
steder. Tilføj kun en beslutning til loggen, hvis den forventes at have betydning
for senere arbejde. Ved nye officielle faglige dokumenter bevares årstal i
filnavnet, og kildeoversigten opdateres.
