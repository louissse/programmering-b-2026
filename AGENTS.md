# Agentvejledning

Dette repository er undervisningssite og materialebank for Programmering B
2026. Start i [`docs/README.md`](docs/README.md), som viser videre til projektets
arbejdsgrundlag, faglige kilder og beslutninger.

Ved planlægning eller vurdering af undervisning skal du bruge den lokale skill
[`plan-undervisning`](.agents/skills/plan-undervisning/SKILL.md) og faggrundlaget
i [`docs/faggrundlag/`](docs/faggrundlag/README.md).

Arbejd kun i dette repository. De to naborepositories er referencekilder og må
ikke redigeres uden udtrykkelig besked. Læs `git status`, bevar brugerens
ændringer, og commit eller push kun efter udtrykkelig anmodning.

Skriv elevvendt indhold på dansk. Bevar siden som enkel, responsiv HTML/CSS med
relative interne links, medmindre brugeren godkender en anden retning.
